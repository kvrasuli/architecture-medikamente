## Проблемные зоны

* Вся внутренняя информация, связанная с пациентами, хранится в файлах в общей папке. Доступ и обмен никак не контролируется,
возможен несанкционированный доступ, утечки, утрата данных. Данные не защищены.
* Персональные данные пациентов попадают во внешнюю систему
* ПД содержат избыточную информацию
* Нет классификации данных по критичности, нет внутреннего аудита и мониторинга работы с данными

## Предложения по улучшению

* Перейти на хранение данных в БД с шифрованием, избавиться от избыточных данных, провести классификацию
* Внедрить единую аутентификацию и авторизацию через AD для всех систем
* Внедрить RBAC для пользователей
* Использовать HTTPS для обмена данными в системе
* Внедрить систему аудита и мониторинга
* Внедрить 2FA для пользователей
